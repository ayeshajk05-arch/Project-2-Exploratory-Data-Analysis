# Project 2 - Exploratory Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on the employee dataset to identify trends, distributions, and key insights.

## Dataset
Employee Dataset (Cleaned)

## Analysis Performed
- Descriptive Statistics
- Gender Distribution Analysis
- Education Distribution Analysis
- City-wise Distribution Analysis
- Outlier Analysis
- Key Observation Summary

## Key Findings
- Total Employees: 2764
- Average Age: 30.95
- Bangalore has the highest employee count
- Bachelor's degree is the most common qualification
- No significant outliers were observed

## Tools Used
- Google Sheets
- Microsoft Excel
